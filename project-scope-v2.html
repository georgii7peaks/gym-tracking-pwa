Gym Tracking PWA

Installable, offline-first React 19 PWA for personal strength-training tracking: build Routine Days, start a Session that snapshots and pre-fills from history, log sets inline with a rest timer, and review Total Volume / Total Duration over time. There is no HTTP API — the UI reads through composite queries and writes through the operations layer over a repository port backed by IndexedDB.

StackReact 19, React Router v7, TypeScript (strict), Tailwind v4, Zustand
DataDexie / IndexedDB (local source of truth); optional Cloud Firestore sync
Project foldersrc/ (domain / data / sync / app / components / prefs / i18n / theme / lib)
Key dependenciesdexie, firebase, react-router-dom, zustand, lucide-react, vite-plugin-pwa
